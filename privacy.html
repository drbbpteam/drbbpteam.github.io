개인정보처리방침

이 방침은 DRB 내부 뉴스레터 운영용 앱인 DRB Newsletter Mac이 Google 계정과 메일 자료를 처리하는 방법을 설명합니다.

접근하는 정보와 목적

계정 확인에 필요한 이메일 주소, 수집 대상 메일 및 발송 확인 대상 메일의 제목·발신자·수신자·날짜·본문·메시지 ID·발송 상태를 처리합니다. 수집 대상 알림 메일의 기사 정보는 뉴스레터 작성에 사용하고, 보낸 메일은 중복 검사와 발송 결과 검증에 사용합니다.

gmail.readonly는 메일 읽기에, gmail.send는 지정된 수신자에게 뉴스레터를 보내는 데 사용합니다. Google이 부여하는 읽기 권한은 메일함 전체에 적용되지만, 앱의 조회는 뉴스레터 운영에 필요한 범위로 제한합니다.

처리와 저장

공식 Gmail API를 사용하는 전송 프로그램(deliver.py)이 발송 전 기존 원장과 보낸 메일을 대조합니다. 발송 후에는 Google이 반환한 메시지 ID, 저장된 메일 본문, 중복 여부를 확인합니다. 발송 결과가 불명확하면 자동으로 재발송하지 않습니다.

수집 자료, 발행 문서, 메일 본문과 검증 응답, 메시지 ID, 본문 해시 및 실행 기록은 운영자가 관리하는 로컬 저장소와 발송 원장에 보관합니다. OAuth 인증 정보는 접근을 제한한 별도 파일에 저장하며 공개 저장소나 이 안내 사이트에 올리지 않습니다. Google과의 API 통신에는 HTTPS를 사용합니다.

전송과 외부 서비스

뉴스레터 메일은 Google Gmail을 통해 지정된 수신자에게 전달됩니다. 발행용으로 선택·검토한 기사 정보와 요약은 뉴스레터와 발행 웹페이지에 포함될 수 있습니다. 메일함 전체나 인증 정보를 공개하는 용도로 사용하지 않습니다.

운영자가 OpenAI Codex 등 연결된 도구로 수집·검토 작업을 수행할 때 해당 작업에 필요한 메일·기사 정보가 그 서비스에서 처리될 수 있습니다. 이 앱은 Google 사용자 데이터를 판매하거나 광고 타기팅 및 범용 AI 모델 학습에 사용하는 기능을 제공하지 않습니다. Google API에서 받은 정보의 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.

보관과 삭제 요청

자료와 발송 기록은 뉴스레터 운영, 오류 확인 및 중복 방지에 필요한 동안 보관합니다. 현재 일괄 자동 삭제 주기는 설정되어 있지 않습니다. 삭제 요청은 아래 연락처로 접수할 수 있으며, 운영 기록과 백업을 포함한 처리 범위 및 완료 여부를 확인해 안내합니다.

Google 계정의 서드 파티 연결 관리에서 앱 접근을 철회할 수 있습니다. 접근 철회만으로 이미 로컬에 보관된 자료가 자동 삭제되지는 않습니다. 로컬 자료 삭제가 필요하면 별도로 요청해 주세요.

이 안내 사이트

이 사이트는 앱 소개와 개인정보처리방침만 공개하며 로그인 양식, 메일 업로드, 자체 분석·광고 추적 기능을 제공하지 않습니다. 호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.
